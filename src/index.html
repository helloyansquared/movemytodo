To Apple Reminders

On a Mac (anything from the last few years): download the import file and run one command. It adds a new Reminders list for each To Do list, and iCloud syncs them to your iPhone and iPad.

  • Lists
  • Notes and links
  • Due dates and reminder times
  • Important → flagged, high priority
  • Completed tasks (marked done)
  • Steps go into the notes as a checklist
  1. Open Terminal (press ⌘ Space, type Terminal, press Return).
  2. Paste this and press Return: 
    osascript -l JavaScript ~/Downloads/import-to-reminders.js
  3. If macOS asks whether Terminal may control Reminders, click OK. You'll see “Done: added … reminders”.

No Mac? Read how to get To Do lists into Reminders on an iPhone (free, with a few limits).

To Things 3

Open this page on the Mac, iPhone or iPad where Things is installed, then tap each button. Each To Do list becomes a Things project (big lists come in parts of 40).

  • Lists → projects
  • Steps → checklist items
  • Notes and links
  • Due dates → deadlines
  • Reminders → “when” with time
  • Categories → tags

To Google Tasks

Creates a new Google Tasks list for each To Do list and adds your tasks in the same order. Works on Android, iPhone, Gmail and Google Calendar.

  • Lists
  • Steps → subtasks
  • Notes and links
  • Due dates
  • Completed tasks (marked done)
  • Repeat rules and reminder times are written into the notes (Google's API can't set them)

Before you connect: Google's review of MoveMyTodo isn't finished yet, so Google shows an extra warning screen (“Google hasn't verified this app”) before you can allow access. If you're happy to continue, choose Advanced on that screen.

We ask for Google Tasks only (not Gmail, Drive or anything else). Your tasks go straight from this tab to Google; we never receive or store them. How we use Google data.

Until Google finishes verifying MoveMyTodo, moving to Google Tasks is part of Pro, because Google allows unverified apps only 100 users in total. The free move works for Apple Reminders and Things 3, and Todoist files are always free.

Todoist, TickTick, Notion and others

  • Todoist has its own free Microsoft To Do importer: todoist.com/importer/microsoft-todo. It copies the lists you pick with due dates, notes and steps. If you'd rather import a file, the Todoist CSV files below still work (up to 300 tasks per file).
  • TickTick has its own importer too, in its web app under Settings → Integrations & Import.
  • Notion, Airtable, Excel, Google Sheets: use the free CSV backup above. In Notion, choose Import → CSV.
  • Obsidian or any notes app: use the free Markdown backup.
